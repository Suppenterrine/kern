## ⚠️ Breaking Changes

### `/reduce` liefert `total` nur noch auf Anforderung

```bash
# vorher: total war immer dabei
curl ".../reduce?input=hello,world"
→ {"items":[…],"total":7}

# jetzt:
curl ".../reduce?input=hello,world"
→ {"items":[…]}

curl ".../reduce?input=hello,world&total=true"
→ {"items":[…],"total":7}
```

Eine Summe, die nie angefragt wurde, ließ sich nicht von einer berechneten
unterscheiden — und jeder Aufruf zahlte für sie.

**Der Parameter `onlyTotal` ist entfallen.** Er tat zwei Dinge auf einmal
(Summe berechnen *und* Items verstecken); `items` sind jetzt immer enthalten.

### `/date` liefert `meaning` nur noch auf Anforderung

```bash
curl ".../date?range=0..3"                → ohne Bedeutungen
curl ".../date?range=0..3&lookup=true"    → mit Bedeutungen
```

Bedeutungen sind Lookup-Informationen. Die TTY-Ausgabe des CLI hat sie nie
gezeigt, die gepipte und die API dagegen immer — dieselbe Anfrage, drei
verschiedene Antworten. Jetzt entscheidet überall dasselbe Flag: `--lookup` im
CLI, `lookup=true` in der API.

### CLI: `-d` ohne `--lookup` zeigt keine Bedeutungen mehr

Betrifft nur die gepipte JSON-Ausgabe; die TTY-Ausgabe war schon immer so.

## Entfernt

Das Farb-Theme (`src/ui/theme.rs`) ist raus. Es war vorbereitet, aber nie
angeschlossen: `current_theme()` gab fest „keine Farben" zurück. KERN bleibt
bewusst monochrom.

meldet nichts mehr. Darunter `select_ciphers`, das `&Box<dyn Cipher>` zurückgab,
obwohl die Aufrufer nur Trait-Methoden benutzen.
